# Model Context Protocol (MCP) Client (`packages/mcp-client`)

The MCP Client package implements standardized tool interfaces for external context collection:

## Available MCP Tools
- `githubSearch`: Crawls GitHub repos, release notes, and code snippets.
- `rssParseFeed`: Scrapes technical RSS feeds (HackerNews, Dev.to, ProductHunt).
- `redditGetTrending`: Retrieves top-voted posts from technical subreddits.
- `googleSearch`: Technical web search and documentation indexing.
- `browserScrapePage`: Headless page text extraction.
- `filesystemReadDoc`: Reads local markdown knowledge base documents.
